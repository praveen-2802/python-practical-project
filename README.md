# Fibonacci Series

## Description
This Python program prints the Fibonacci series for the number of terms entered by the user.

## How It Works
The series starts with `0` and `1`. Each following number is the sum of the previous two numbers.

## Requirements
- Python 3.x

## How to Run
1. Open a terminal in the folder containing `fibonacci.py`.
2. Run:
   ```bash
   python fibonacci.py
   ```
3. Enter a non-negative integer when prompted.

## Concepts Used
- Variables
- `input()` and `print()`
- `for` loop
- Multiple assignment
- Conditional statements
